# 实机远端边深度丢失诊断实验 —— 实验方案

> 配套脚本：[diag_far_edge_depth.py](./diag_far_edge_depth.py)
> 运行与开展实验：[far_edge_diag_run_guide.md](./far_edge_diag_run_guide.md)

---

## 1. 实验目的：把一个猜想坐实成参数

**猜想（部署偏置的根因链）：**

```
仿真深度完美 → 训练点云里工件远端轮廓也在（远端点存在）
D435 实机深度在远端边丢失 → 掠射角 + 边缘纹理弱，红外散斑不返回 → depth = 0
部署反投影时 depth>0 过滤 → 远端点被剥掉
FPS 最远点采样偏爱极端点 → 远端锚点消失 → 点云质心向相机方向偏
```

每个环节在代码里都能对上号：

| 环节 | 代码位置（不修改，只引用） |
|---|---|
| 反投影与 depth>0 过滤 | `scripts/camera/real_roi_pointcloud.py` → `mask_depth_to_pointcloud` |
| FPS 采样 64 点 | `configs/point_bridge_pointcloud.py`（训练/部署同源） |
| 仿真深度 | Isaac Lab 光线投射，边缘无损 |

**本实验要做的事：**

1. 在实机上**量化**"远端边深度到底丢了多少、带有多宽"；
2. 证明这个丢失是**稳定系统性**的（不是偶发帧噪声）；
3. 把"缺失带宽度(mm)"**直接换算成训练侧远边腐蚀的 band 参数**。

> 说明：训练侧的随机遮挡（random_box）挖的是**相机朝向的近面**，与远端丢失是正交的失败模式，所以本实验不是给 random_box 调参，而是给新的"远边腐蚀"策略定参数。

## 2. 实验流程总览（S0–S4）

| 阶段 | 名称 | 做什么 | 输出 |
|---|---|---|---|
| S0 | 相机就绪 + 内参/外参对照 | 起相机、实机内参 vs 仿真 canonical、外参核对 | 命令行对照表 |
| S1 | 标注工件 ROI | 鼠标手标多边形（或 `--polygon` 复用） | 掩码 mask |
| S2 | **单帧远边诊断（核心）** | 近端 vs 远端空洞率对照 + 远端内收量(mm) | 判定 + `s2_overlay.png` |
| S3 | 稳定性采集 | 连采 N 帧，看缺失是否稳定 | `s3_stability.csv` + 趋势图 |
| S4 | 点云级验证 + 汇总报告 | 真机反投影 64 点，量质心偏置 | `s4_points.npy` + 最终报告 |

实验设计原则：**所有几何与反投影复用训练/部署同一套代码**（`mask_depth_to_pointcloud`），否则测出来"真机路径"和"训练路径"不是同一条，结论没有说服力。

## 3. 重点阶段 S2 详解（每一步的专业动作与理由）

S2 要回答两个问题：
- **Q1**：空洞是不是**单侧**（远端）聚集？——用"路线 A"回答；
- **Q2**：远端到底**内收了多少毫米**？——用"路线 B"交叉验证。

两条路线互相独立（A 依赖外参，B 不依赖外参），结论一致才可信。

### 3.1 路线 A：外参空间分半（近端 vs 远端对照）

**步骤 A1：定"远方向"（compute_far_axis）**

- 先对深度图中值滤波去噪（5×5），再对每个有效像素取**归一化深度梯度**，取中值方向 `(du, dv)`。
  - 原理：深度场在图像上的梯度指向深度增加最快的方向——对远离相机而倾斜的表面，该方向就是"远端"。图像里的"上/下/左/右"没有物理意义，深度梯度才是与几何绑定的方向。
  - 为什么取中值而不是均值：远端空洞边界处梯度会反向（指向洞内），个别像素/局部法向噪声也会扰乱，中值对这类野值稳健；同时采样时腐蚀掉空洞边界 3 px，避免梯度伪影。
  - 为什么不能用"把锚点沿远方向移动后投回图像"来求方向：锚点和锚点+ε·(锚点−光心) 两点都在**同一条相机射线**上，投回图像是同一个像素，位移恒为 0——这是几何上必然退化的写法。
  - 附带输出一致性：各像素梯度与中值方向的平均投影。若 < 0.5（工件正面朝向相机、深度场平坦），"远/近"空间分半失去意义，自动转以路线 B 为准。
- 取有效深度的**中位数** `d_med`（远端空洞会把均值拉向近处——幸存者偏差，中位数稳健），反投影掩码质心到基座系得到工件锚点 `P_obj`；`d3 = (P_obj − P_cam)/‖·‖` 供 S4 点云级沿远轴投影用。
- 中位深度处 1 px ≈ `d_med / fx` 米——这是路线 A 内收量 px→mm 换算的尺子。

**步骤 A2：近远分半（split_near_far）**

- 对掩码内每个像素，算带符号投影 `s = (u−cu)·du + (v−cv)·dv`：`s≤0` 为近半，`s>0` 为远半。
- 这等价于**拿一把经过工件质心、垂直于"相机→工件"方向的刀**，把工件切成近/远两半。

**步骤 A3：两半各自的空洞率（half_hole_ratio）**

- `空洞率 = 1 − 有效像素数/掩码像素数`，近半远半各算一个。
- 关键判据是**比值**：远/近空洞率比 ≫ 1 ⇒ 缺失单侧聚集在远端。
  - 比值的好处：与工件材质、打光、绝对空洞水平无关，只看**空间不对称性**——即使整体空洞率很高（反光），只要近远对称，就不是远边问题。

**步骤 A4：远端内收量（recession_width）**

- 思路：**多边形是"真实边界"，有效深度掩码是"实际测到深度的边界"**。远边丢深度时，有效掩码的远边界会内收进多边形远边界以内，内收宽度就是缺失带宽度。
- 两个边界的读法**不对称**（自检发现纯分位读法会把内收量系统性读小）：
  - 多边形远边界取 **max(s_多边形)**：手标轮廓沿远轴最远的像素就是远端尖点、真实边界。用 98% 分位的话，远端尖帽像素太少，分位会缩进尖点以内好几像素。
  - 有效掩码远边界取 **p98(s_有效)**：D435 在轮廓边缘偶有飞点把深度溅出真实边界之外，max 会被飞点污染；p98 免疫。
  - 同时打印 `max − p98(s_多边形)`（尖帽量），> 8 px 提示多边形远端可能标出界、内收量被高估，建议重新标注。
- 换算毫米：`mm = px · d_med / fx · 1000`（针孔几何：深度 z 处 1 px 的物理宽度 = z/fx）。
- **这个毫米数就是训练侧远边腐蚀要用的 band。**

### 3.2 路线 B：深度分箱剖面（外参无关交叉验证）

路线 A 依赖手标外参 `CALIB_CAM_POS_IN_BASE_M`。如果外参本身有误差，A 的分半就错了。所以 B 完全不碰外参，只用深度图自身的物理量：

- **有效像素**按深度等分箱（np.quantile 分箱，近→远），每箱算空洞率。
- **空洞像素（depth=0）无法按自己的深度分箱**（它的深度就是 0，没有信息），所以用 scipy `cKDTree` 找**最近的有效像素**，把那个像素的深度"借"给空洞，再归箱。
  - 理由：深度空洞几乎总是紧贴着有效区域向轮廓内侵蚀（掠射角只在边缘），最近有效像素的深度是空洞深度的最佳无偏估计。
- 若"远箱空洞率 ≫ 近箱空洞率"，则与 A 结论互证；若两条路线矛盾，优先怀疑外参/内参（进入第 4 节第 3 分支）。

### 3.3 S2 判定（三分支 → 训练决策）

| 判据 | 判定 | 训练侧动作 |
|---|---|---|
| 远/近空洞率比 > 2 **且** 内收 > 1 mm | 单侧远边缺失 | **确定性远边腐蚀**，band ≈ 内收量 |
| 空洞率高但近远接近对称 | 轮廓边缘空洞（绕边均匀） | 对称的轮廓边缘腐蚀 |
| 空洞率低或内收不明显 | 未见远边缺失 | 查内参对齐/掩码来源，跑 S4 点云核对 |

## 4. 其余阶段说明

### S0 相机就绪 + 内参/外参对照

- 启动 RealsenseCamera（640×480@30，硬件深度对齐），预热 30 帧（自动曝光与滤波收敛）。
- `report_intrinsics` 打出实机内参，与仿真 canonical（fx=fy=615, cx=320, cy=240）对照——实机内参偏差过大会直接造成反投影系统性偏。
- `_verify_extrinsics` 核对相机位姿与 configs 里标定值一致（换过相机支架/相机后必须先核对）。
- `--intrinsics sim/real` 可切换反投影用哪套内参，用来隔离"内参差异"这个变量。

### S1 标注工件 ROI

- 鼠标手标多边形（沿工件可见轮廓，≥3 点），回车确认；`--polygon "x,y x,y ..."` 可复用上次标注（同一位姿实验不需要重标）。
- 面积 < 200 px 会警告：候选点太少，FPS 采样大量重复，点云退化。

### S3 稳定性采集（N 帧，默认 30）

- 工件静止，连续采 N 帧，每帧重算远半/近半空洞率与内收量，命令行每 5 帧打印一行 + 实时汇总。
- 判读：内收 > 1mm 的帧占比 > 80% 且 std 小 ⇒ **稳定系统性缺失**（做确定性腐蚀）；时而出现 ⇒ 随机腐蚀/加噪，band 取分布上界；基本不出现 ⇒ 回到内参/掩码。
- 逐帧序列落盘 `s3_stability.csv`，可选 matplotlib 趋势图 `s3_trend.png`。

### S4 点云级验证 + 汇总报告

- 用共享 `mask_depth_to_pointcloud`（noise_std=0）把真机深度反投影成基座系 64 点——**和部署完全同一条代码路径**。
- 量两个量：沿远轴 `d3` 的远端延伸 vs 近端延伸（远端更短 = 被截断）；点云质心相对工件锚点沿 `d3` 的偏移（**负 = 向相机偏**，即部署偏置本身）。
- 点云落盘 `s4_points.npy`（后续可喂给策略网络复现部署行为）。
- 最终汇总：S2 判定 + S3 稳定性 + S4 点云偏移，合成**训练侧远边腐蚀 band 建议值**，写 `final_report.json`。

## 6. 预期结果与后续

- **预期（若猜想成立）**：S2 远/近空洞率比明显 > 2、内收 2–10 mm 量级；S3 稳定出现；S4 质心沿远轴向相机偏。→ 训练侧加入远边腐蚀（band ≈ 实测内收量），复训对比部署偏置。
- **意外但有用**：若近远对称空洞 ⇒ 不是远边问题，是分割/反光问题；若 S4 偏移小但部署仍偏 ⇒ 偏置在更下游（观测编码/策略），诊断结果可排除上游嫌疑。
